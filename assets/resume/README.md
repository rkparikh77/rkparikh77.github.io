# Resume PDFs

Drop the four targeted resume variants in THIS directory (assets/resume/):

- Rahil_Parikh_Resume_UPenn_Lab.pdf   (general / default)
- Rahil_Parikh_Resume_JIRL.pdf        (Loquercio / JIRL)
- Rahil_Parikh_Resume_DAIR_Lab.pdf    (Posa / DAIR)
- Rahil_Parikh_Resume_Figueroa_Lab.pdf (Figueroa Robotics Lab)

The repo-root /resume.pdf is a copy of the JIRL variant and is the stable public
link used on the site and applications. To change which variant is public, copy
the desired file over /resume.pdf.
